# Python To-Do List

A command-line To-Do List application built using Python that helps users organize and manage daily tasks through a simple interactive menu.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Update existing tasks
- Delete tasks
- Input validation
- Prevent empty task entries
- User-friendly command-line interface

## Technologies Used

- Python 3

## Data Structure Used

Each task is stored as a dictionary inside a list.

Example:

```python
{
    "task": "Study Python",
    "completed": False
}
```

## Project Structure

```
todo_list.py
```

## How to Run

1. Clone the repository

```bash
git clone https://github.com/srivarshatech/python-todo-list.git
```

2. Navigate to the project folder

```bash
cd python-todo-list
```

3. Run the application

```bash
python todo_list.py
```
